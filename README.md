# 오퍼월 캠페인 온보딩 도구 · 체험판

캠페인을 열기 전까지 광고주·대행사와 메일로 주고받던 정보를 화면으로 옮긴 도구입니다.
광고주는 필요한 정보를 직접 입력하고 올리며, 운영자는 체크리스트로 확인하고 승인합니다.

## 화면

- **운영자 화면** (`ops.html`): 캠페인 목록, 처리 현황 체크리스트, 계약·서류, 캠페인 세팅
- **광고주 화면** (`advertiser.html`): 안내서, 진행 현황, 계약 정보, 연동·테스트, 광고 소재, 소재 기획 도우미

## 체험판이 동작하는 방식

- 서버 프로그램(파이썬)을 브라우저 안에서 그대로 실행합니다. 따로 서버가 없습니다.
- 입력한 내용은 보는 사람의 브라우저에만 저장됩니다.
- AI 결과는 시연 때 받아 둔 답을 보여 줍니다. 금액 계산, 규격 검사, 체크리스트 같은 규칙은 실제 코드가 처리합니다.
- 회사, 앱, 서류, 금액은 모두 가상의 예시입니다.
